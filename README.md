# Odore Perla Landing Page

## Project Overview
This project is a modern, responsive perfume e-commerce landing page built to showcase perfume products in an elegant and visually appealing way.
The design focuses on creating a premium shopping experience through a clean layout, attractive typography, product imagery, subtle gradients, decorative elements, responsive sections, and interactive components.
The landing page was developed with React and Tailwind CSS, with reusable components used to keep the project organized and maintainable. The page is designed to adapt to different screen sizes, providing a consistent experience across desktop, tablet, and mobile devices.

## Reflection

### My Approach
I approached the task by first breaking the landing page design into smaller, reusable sections instead of trying to build the entire page at once. I studied the reference design and identified important components such as the header, hero section, product cards, image grid, testimonials, and call-to-action sections. I then recreated each section using React components and Tailwind CSS while paying attention to spacing, typography, positioning, and responsiveness.

### Challenges Encountered
One of the main challenges was translating a visual design into a responsive layout. Some sections contained overlapping elements, decorative circles, gradients, and carefully positioned images, which made it difficult to reproduce the design while keeping it responsive. Creating the hero carousel and making the navigation header change its appearance when scrolling also required additional React logic.

### How I Solved Them
I solved these challenges by breaking complex sections into smaller components and using Tailwind's responsive breakpoints to control how layouts behave at different screen sizes. For interactive features, I used React state to manage things such as the carousel and mobile navigation. I also experimented with positioning, flexbox, grid, gradients, and spacing utilities until the layout closely matched the intended design.
### Future Improvements
In future iterations, I would improve the project by adding a complete shopping experience, including product detail pages, cart functionality, search, filtering, and checkout. I would also improve accessibility, optimize images for faster loading, add smoother animations, and connect the frontend to a backend or API for dynamic product data.
